An RPG-style “game” I made using CodeIgniter4.

This files in this repository are a CodeIgniter4 project I started in early 2024. 
The project runs primarily on PHP. It was meant to become an RPG, but I never got past the menu stage after realizing how time-consuming a project like this would be - especially on a framework it really wasn’t designed for.
If you'd like to see how it looks, download the showcase.mp4 file.
